# Net Scout landing page

A responsive light-mode landing page concept for Net Scout, using the selected map-and-compass logo.

## Run locally on Ubuntu

1. Extract the ZIP.
2. Open the `net-scout-website` folder in VS Code.
3. Open the integrated terminal in that folder.
4. Run:

   ```bash
   python3 -m http.server 8000
   ```

5. Open `http://localhost:8000` in your browser.

Stop the server with `Ctrl+C`.

## Important notes

- The waitlist form is a visual preview only. It does not save names, email addresses, or WhatsApp numbers.
- Do not collect real contact details until the form is connected to a secure backend/database and the privacy/consent flow is ready.
- The map artwork is illustrative, not live network coverage data.
- The logo image uses the chosen light-mode map-and-compass concept: smooth blue-to-teal ring, original compass needle, signal arcs, and a detailed map background.
- Google Fonts are loaded online; system fallbacks are provided.
